Motion
=============

## Description

Motion is a program that monitors the signal from video cameras and detects changes in the images.

## This fork

Forked from [Motion home page](https://motion-project.github.io/).

Changes from motion-project:
* Manage the size of on-disk recordings per camera to a size limit.
